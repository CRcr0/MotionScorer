# MotionScorer Interactive Explainer

This folder preserves two versions of the interactive paper explainer.

- `MotionScorer_Interactive_v1.html`: original 17-act version.
- `MotionScorer_Interactive_v2_Detailed.html`: expanded 24-act teaching edition with more detailed equations plus child-friendly animated analogies for attention filtering, the realizable readout family, centering, score-direction estimation, residual nuisance, whitening, teacher-conditioned deflection, and the final objective.

Both versions are intentionally retained for comparison and rollback.
